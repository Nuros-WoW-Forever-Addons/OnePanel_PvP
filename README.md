# OnePanel_PvP

**OnePanel_PvP** is a modular plugin for the [OnePanel Suite](https://github.com/Nuros-WoW-Forever-Addons/OnePanel), replacing the default World of Warcraft Player vs. Player panel with a clean, high-contrast interface designed for WoW Forever Beta.

---

## 🌟 Key Features

- **Faction Honor Crest**: High-resolution Alliance or Horde crest with a circular rank badge medallion displaying military rank from Rank 0 (Civilian) to Rank 14 (Grand Marshal / High Warlord).
- **Dragonflight Gradient Progress**: High-contrast gradient status bar tracking Rank Points progress toward the next rank threshold.
- **Honor Performance Metrics**: Overview of Today's, Yesterday's, This Week's, and Lifetime Honorable Kills and Honor points.
- **Interactive Rewards Drawer**: Preview upcoming rewards at each military rank, view equipment tooltips, and locate faction quartermasters.
- **OnePanel Integration**: Docked as Tab 4 with side drawer synchronization.

---

## 🎮 Slash Commands

- `/oppvp` — Output debug diagnostics for PvP ranks, rank points, and honor stats.
